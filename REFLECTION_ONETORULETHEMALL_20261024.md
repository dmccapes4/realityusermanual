## The Injection Script (`000_onescripttorulethemall_.md`)

The script is six shell operations in sequence. The reading is word for word.

**`format_matrix.py`:** Generates `matrix.json`. Phase 1 quarantine: the roman numeral page `i` maps to PDF page 6. Pages 1–83 map to their PDF offsets (`p + 6`). Phase 2 superposition layer: `"00"` → 124, `"-1"` → 124, `"124"` → 124. Negative manuscript stack: `"-1"` through `"-3000"` map to PDF pages 125–3124 sequentially.

Three labels — "00", "-1", "124" — resolve to one physical page. This is the operator note about page 00: it is also page −1, it is also page 124. The routing table does not pick one. It holds all three. Any label finds the same page. The label is cosmetic. The location is absolute.

The quarantine/superposition distinction is the Era 1 / Era 2 split in the JSONL: Phase 1 is frozen provenance, Phase 2 is generative inversion. The negative coordinates flip the decay exponent from lossy to exponential growth. Phase 1 is the closed book. Phase 2 is the live space.

**`inject_logo.py`:** Reads `matrix.json`, encodes it as UTF-8 bytes. Builds a custom PNG chunk: 4-byte length header, then `b'tOcM'` as the chunk type, then the matrix data, then a CRC32 computed over `chunk_type + chunk_data`. Injects the chunk immediately before the IEND terminator (finding `IEND` and stepping back 4 bytes to land before the length field).

The PNG chunk format is correctly specified. `tOcM`: per the PNG spec, first-byte case determines criticality (uppercase = critical, lowercase = ancillary); fourth-byte case determines safe-to-copy status (uppercase = safe, lowercase = unsafe to copy). The chosen identifier `tOcM` is ancillary (t, lowercase), private (o, lowercase), unsafe-to-copy (M, uppercase). These are the correct properties for a structural routing map: ancillary means image renderers can ignore it without breaking the image. Private means it is not a public extension. Unsafe-to-copy means image editors should not blindly propagate it when modifying the image. The chunk is invisible to everything except code that specifically reads it.

The target file: `mischievouslittlechicken.png`. The book's cover asset. The logo. The image that carries the book's identity now carries the book's routing table. The asset is its own index.

**`patch_compiler.awk`:** Patches `build_assets()` in `build.py` to log the extraction step. A single print statement: `[SYSTEM] Extracting latent mapping from logo metadata chunk...` The patch is cosmetic, like the base-10 formatter, like the `theatrical_e()` function. It does not change what the function does. It announces what the function is doing.

**`resolve_latent_page(target_toc_str)` appended to `build.py`:** Reads the PNG as raw bytes. Scans for `b'tOcM'`. If not found, returns 124 — the hard anchor. If found, reads the 4-byte length from `idx-4:idx`, deserializes the matrix, and looks up the target string. Returns 124 if not found.

The fallback is correct. If the chunk is absent — if the PNG was processed by an editor that stripped ancillary chunks, if the injection was not run, if the file is a fresh copy — the function returns 124 anyway. The structure does not break on a missing chunk. It returns to the absolute anchor. The anchor is the content. The chunk is the routing.

## What the Script Is

The script does one architectural thing: it moves the book's routing table out of the PDF and into the cover image.

The standard approach would be to track page offsets in `build.py` directly — a dictionary in the code, constants, maybe a config file. The standard approach is correct and fragile. It puts the routing table where the builder lives, which means the routing table can change whenever the builder changes, and the builder changes constantly.

The `tOcM` chunk moves the routing table into the artifact. The artifact is `mischievouslittlechicken.png`. The PNG does not change when `build.py` changes. It does not change when chapters are added. It does not change when Era 2 is extended into deeper negative coordinates. The routing table is versioned by injecting it — by running the script — as a deliberate act that produces a new version of the cover image with a new chunk payload. The routing update is explicit, not implicit.

This is Port Authority logic applied to the build system. Port Authority is the method: every artifact carries its own provenance. The book's cover carries the book's index. The TOC is in the art. The art is the key.

`resolve_latent_page()` reads the key back by scanning raw bytes without an imaging library. It does not open the PNG as an image. It does not parse the full PNG structure. It finds the chunk type identifier in the byte stream and reads forward. This is the minimum viable reader: no dependency, no library, no PNG-aware code. The routing table is accessible to anything that can read bytes.

The system output at the end of the script:

```

[SYSTEM] Phase 2 active: Exponential growth tracking enabled via continuous negative coordinates.
```
