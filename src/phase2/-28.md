set to Apply Manually. No agent was shown it. The name appeared in agent output.
The operator noticed, navigated to the rule, pointed at the dropdown — and the session

The frontmatter is now `alwaysApply: true`. The rule is in context on every invocation.

The rule text was correct from the first day. The mechanism was the error.

*Apply Manually* is not a weaker Always Apply. It is a different mechanism for a different
purpose: context-sensitive rules, file-type rules, rules with narrow domain applicability.
A universal rule set to Apply Manually is not conservatively applied. It is unenforced.

The operator-not-name rule's scope section says "all files, all chat responses, all
document headers." That scope does not have a qualifier. The setting should match the text.
Now it does.
