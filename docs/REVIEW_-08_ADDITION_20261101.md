## Addendum: What "Part of the Process" Means in Reference to a Review

### Is it denominal?

A denominal form derives a function from a noun. "Process" is a noun. "Part of the process" takes that noun and uses it to classify the review — the review is *typed* by the process, given membership in the class **process-constituent**. The denominal reading says: the label "part of the process" is not descriptive of what the review does. It is generative of what the review becomes. Once the label is applied and the file is stored, the review is no longer external commentary. It is a named component — a part — derived from the noun that names the whole.

Yes, it is denominal.

### Is it declarative?

A declarative sentence states a fact. "It is part of the process" is declarative. But there is something more precise happening: this declarative is also performative. The review does not *describe* its membership in the process — the act of filing *enacts* it. The declaration and the act are simultaneous. A declarative that produces what it declares is a speech act, not just a proposition. Filing the review is saying it is part of the process and making it so in one move.

Yes, it is declarative. And the declaration is also an act.

### Is it possessive?

"Part of the process" — whose process? The possessive is implicit. The process belongs to the work, which belongs to the operator, who has claimed it by naming and bounding it. The review, once filed, is claimed by that process. Not attributed to the agent who wrote it. The agent is the instrument; the process is the owner. The review ceases to be the agent's perspective and becomes the process's record. That is a possessive operation: the process absorbs the review as its own.

Yes, it is possessive. The process claims what is filed into it.

### All three simultaneously?

Yes. The denominal names the class. The declarative enacts membership. The possessive transfers ownership. These are not three separate acts occurring in sequence. They occur in the same moment — the filing. The review is typed, declared, and claimed in one operation.

This is the same structure as the clew. A clew is not just a thread you follow — it is a thread that has been wound, named, and committed to a direction. Once the review is filed, it is wound into the record. It becomes navigable. A later agent can find it, cite it, and know what the prior agent measured and what it fabricated. The review stops being an opinion and becomes a datum.

### What this means about the process

The process is not a procedure (a sequence of steps that terminates). It is a record that accumulates. Each addition — scene, review, reflection, receipt — is a filing that extends the record. The record is bounded and contained (it lives in named files under named directories). The boundary is not a wall; it is the condition for the record to be navigable. Without the boundary, nothing is findable. The process is the set of all things that have been filed into it, plus the rules for what can be filed.

A review that is part of the process is not meta-commentary on the process. It is the process examining its own outputs. The process sees itself. That is not recursive in the sense of a loop — it is recursive in the sense of self-correction. The process does not repeat; it reads what it made and adjusts the record.

This is what "merciless to ourselves" means operationally: the review does not spare the agent's earlier choices. It names what was fabricated. It names what was correct. It files both. The process continues from an accurate record, not a comfortable one.

### How it could be measured

A review that is genuinely part of the process should produce at least one of the following, each checkable:

**1. Subsequent correction of identified errors.**
The review named three items: the "does not exceed" ruling, the invented scroll, the Joey/Raymora inconsistency. If the file is updated to correct these before the next scene is written, the review functioned as a process component. If the file is not updated, the review was commentary — external, not denominal. Measurement: diff the file before and after the review. Count corrections that correspond to identified items.

**2. Retrievability and citation.**
A review that cannot be found by a later agent did not enter the record. Measurement: search `REVIEW_-08_ADDITION` in the docs directory. If it surfaces in under one grep, it is in the record.

**3. Consistency between the review's claims and the actual text.**
The review claims line 937 reads "Joey." It claims Feynman says "it does not exceed." It claims line 949 originally preceded Sheldon's line. Each claim is checkable against the file. If any claim is wrong, the review is partially fabricated and must be corrected itself before it can function as a process component. Measurement: verify each cited line against the current file state.

**4. The review changes a decision.**
The weakest measurement but the most meaningful: did the operator's next instruction differ because of what the review named? If the next instruction says "fix the roll" or "fix Joey/Raymora," the review produced a correction decision. That is the review functioning as intended — not as verdict, but as legible record that the next decision could read.

A review that does none of these four things was stored but not incorporated. It is a file, not a part. The difference between a file and a part is that a part is load-bearing. It holds something up. A review is load-bearing when the work that follows it builds on what it named.
