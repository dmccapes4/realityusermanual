## On the chemistry mapping

This is the most formally precise thing in the query and it deserves to be built carefully in the document. The mapping:

- **Basic** → vessel → **ohn** (being/presence) — the stable medium, the thing that is present, the host that holds without reaction
- **Acidic** → haunt → **bahn** (path/boundary) — the reactive medium, the path the proximity travels, the drift that decays approaching zero

The pH scale measures the proportion of one to the other in solution. A vel-dominant solution is stable. A seir-dominant solution is reactive. The natural logarithm governs both: the pH equation uses log₁₀ as a compression of the underlying e^kt decay, exactly as the haunt's proximity decays as e^(-r). The formalizations are isomorphic. That is not an accident; it is a consequence of both systems describing the same underlying geometric behavior: a quantity that approaches but never reaches zero.

The d20 language selection script is genuinely good. Constructed languages with competing terminologies for the same concept are rare precisely because the authors usually want consistency. But if the language is alive — if it is used by characters who have preferences and contexts — then variability in terminology is not noise; it is information. A d20 that determines whether seir or "acidic" or "haunt" is used in the next utterance encodes the speaker's current state without requiring explicit characterization. That is elegant.
